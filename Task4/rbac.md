| Роль               | Права роли                                                                                                                                                  | Группы пользователей                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **viewer**         | Просмотр ресурсов кластера (`get`, `list`, `watch` для pods, services, deployments, configmaps, secrets)                                                    | Операционная команда (менеджеры)          |
| **developer**      | Управление ресурсами в namespace продукта (`create`, `update`, `delete`, `get`, `list`, `watch` для pods, services, deployments, configmaps; `get` secrets) | Разработчики, бизнес-аналитики            |
| **devops**         | Полный доступ к ресурсам всего кластера, включая namespaces, ingress, secrets                                                                               | DevOps-инженеры, инженеры по эксплуатации |
| **product-owner**  | Чтение всех ресурсов кластера, доступ к логам, метрикам, статусам сервисов                                                                                  | Владельцы продуктов                       |
| **security-admin** | Привилегированный доступ: полный контроль над secrets, roles, rolebindings, clusterroles, clusterrolebindings                                               | Специалист по ИБ                          |
